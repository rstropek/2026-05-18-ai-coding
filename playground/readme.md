# Introduction

This program is a simple tool for demonstrating basic LLM features. It demonstrates inline suggestions using fibonacci sequence generation, and also includes a simple command-line interface for user interaction.

| Feature                       | Description                                                            |
| ----------------------------- | ---------------------------------------------------------------------- |
| Inline suggestion             | Demonstrates how the LLM can provide real-time suggestions             |
| Fibonacci sequence generation | A simple example of a computational task that the LLM can assist with  |
| Console interaction           | Allows users to interact with the LLM through a command-line interface |
